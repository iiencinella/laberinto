# Juego de laberinto

El juego de laberinto en el que se pondrá a prueba al usuario la motricidad y la concentración en el uso del mouse (en la versión de escritorio) o en la pulsación (en la versión mobile).

## Características

- El juego se desarrollará en HTML, CSS y javascript
- Debe ser responsivo
- Debe detectar el dispositivo en el que se abre el juego para estar atento al mouse o las pulsaciones.

## Funcionalidades

- Habrá 3 niveles. El primero es el más fácil, el segundo es de nivel medio y el tercero es un nivel dicícil.
- Se tiene que dibujar un laberinto de varios caminos pero del cual un camino es el correcto (el resto lleva a una pared).
- Se tiene que marcar el punto de entrada y el punto de salida del laberinto.
- Se tiene que registrar en el mapa el camino que realiza el usuario.
- Se tiene que registrar el tiempo en el que el usuario demora en ir desde el punto de entrada hasta el punto de salida del laberinto.
- Se tiene que contar la cantidad de veces que el usuario toca la pared. Esto se debe de hacer para indicar el nivel de concentración y motricidad que tiene el usuario.
- Debe de haber un botón que permita reiniciar el nivel en el que está el usuario y un segundo botón para reiniciar todo el juego.
- El juego debe de registrar el tiempo en el que el usuario terminó el juego y sus tiempos en cada nivel. En este punto se le debe de pedir un nombre de usuario. Estas estadísticas se tienen que guardar en localstorage.
